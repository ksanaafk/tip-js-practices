## Задание 2. Исследование типов и преобразований

**Цель задания:** Исследовать основные типы данных JavaScript и особенности их преобразования при выполнении различных операций.

В файле `js/types.js` была создана программа для проверки десяти выражений. Для каждого выражения определены предполагаемое значение, фактический результат и тип данных.

### Результаты проверки

| Выражение | Ожидание до запуска | Фактическое значение | Тип результата | Объяснение |
|---|---|---|---|---|
| `"8" + 2` | `"82"` | `"82"` | `string` | Число преобразуется в строку, происходит объединение строк. |
| `"8" - 2` | `6` | `6` | `number` | Оператор вычитания преобразует строку в число. |
| `Number("8") + 2` | `10` | `10` | `number` | Функция Number() преобразует строку `"8"` в число 8. |
| `"12" > "3"` | `false` | `false` | `boolean` | Строки сравниваются посимвольно. Символ `1` меньше `3`. |
| `12 === "12"` | `false` | `false` | `boolean` | Строгое равенство учитывает типы данных. Число и строка не равны. |
| `Number("")` | `0` | `0` | `number` | Пустая строка при числовом преобразовании становится нулём. |
| `Number("text")` | `NaN` | `NaN` | `number` | Строку невозможно преобразовать в число, поэтому получается NaN. |
| `Boolean("false")` | `true` | `true` | `boolean` | Любая непустая строка при логическом преобразовании даёт true. |
| `typeof null` | `"object"` | `"object"` | `string` | Историческая особенность JavaScript. Сам оператор typeof возвращает строку. |
| `typeof NaN` | `"number"` | `"number"` | `string` | NaN относится к числовому типу, а typeof возвращает строку с названием типа. |

### Запуск программы

Из корневой папки репозитория выполнена команда:

```bash
node practice-01/js/types.js
```

### Вывод

В ходе выполнения задания были исследованы основные типы данных JavaScript и особенности их преобразования.

Установлено, что оператор `+` может объединять строки, а оператор `-` выполняет числовое преобразование. Пустая строка преобразуется в `0`, некорректная числовая строка — в `NaN`, а любая непустая строка — в логическое значение `true`.

Также были изучены особенности оператора `typeof` и строгого сравнения `===`.

## Задание 5. Поиск логических ошибок через DevTools

**Цель задания:** Научиться находить и исправлять логические ошибки в JavaScript с помощью инструментов разработчика браузера.

**Исходный результат выполнения:**

```text
Выполнено: 32
Осталось: -24
Контрольная сумма: 6
```

Для поиска ошибок использовался отладчик Firefox DevTools.

Во вкладке «Отладчик» была установлена точка останова на строке вычисления `completedTotal`. С помощью пошагового выполнения программы и просмотра значений переменных было установлено, что `completedText` и `additionalText` имеют строковый тип.

При выполнении операции `"3" + "2"` произошло объединение строк, в результате чего переменная `completedTotal` получила значение `"32"` вместо числа `5`.

Затем была установлена точка останова внутри цикла `for`. При пошаговом выполнении выяснилось, что цикл выполняется только для значений `taskNumber` от 1 до 3, поскольку условие `taskNumber < 4` не включает число 4.

### Результаты отладки

| Ошибка | Что наблюдалось | Причина | Исправление | Результат после исправления |
|---|---|---|---|---|
| Обработка количества задач | Выполнено 32, осталось -24 | Конкатенация строк вместо сложения чисел | Преобразование строк с помощью `Number()` | Выполнено 5, осталось 3 |
| Граница цикла | Контрольная сумма 6 | Условие `taskNumber < 4` исключало число 4 | Замена условия на `taskNumber <= 4` | Контрольная сумма 10 |

### Результат после исправления

После преобразования строк в числа и исправления границы цикла программа была повторно запущена в Node.js и браузере.

**Результат:**

```text
Выполнено: 5
Осталось: 3
Контрольная сумма: 10
```

### Вывод

В ходе выполнения задания были изучены возможности отладки JavaScript-программ с помощью Firefox DevTools.

С использованием точек останова и пошагового выполнения обнаружены две логические ошибки: объединение строк вместо арифметического сложения и неправильная граница цикла.

После внесения исправлений программа стала выдавать ожидаемые результаты.
